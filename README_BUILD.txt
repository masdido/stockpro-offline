STOCKPRO OFFLINE - PROJECT APK

Cara build:
1. Buka folder project ini di Android Studio.
2. Tunggu Gradle selesai sync.
3. Pilih Build > Build APK(s).
4. APK debug akan berada di:
   app/build/outputs/apk/debug/app-debug.apk

Aplikasi berjalan offline dan menyimpan data di perangkat menggunakan localStorage.
Tidak membutuhkan server/cloud.

Catatan: project ini adalah versi awal/MVP. UI dan logika bisnis utama ada di assets/index.html.
